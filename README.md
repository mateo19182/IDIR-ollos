# Aliñamento de imaxes oftalmolóxicas usando representacións neuronais implícitas

Implementation of retinal image registration using Implicit Neural Representations (INRs), based on the [IDIR framework](https://github.com/MIAGroupUT/IDIR).

## About

This repository contains the implementation code for adapting the IDIR framework for 2D retinal image alignment, developed as part of my computer science degree thesis.

[mateo19182/TFG](https://github.com/mateo19182/TFG) - Contains the written thesis and presentation slides.
